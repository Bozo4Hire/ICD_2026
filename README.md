# Repositorio | Introducción a la Ciencia de Datos (ICD 2026)

Este es mi repositorio para la materia de Introducción a la Ciencia de Datos. Aquí se encuentra todo lo que se ha asignado como tarea o trabajo como parte del curso.

La materia es la primera de una secuencia de tres (después siguen Ciencia de Datos para Sensado Inteligente y Reconocimiento de Patrones). El temario tiene 7 unidades: introducción, procesamiento de datos, regresión, aprendizaje supervisado, aprendizaje no supervisado, meta-aprendizaje y aprendizaje profundo. Durante el semestre se estarán realizando 5 lecturas, 5 prácticas y un proyecto final.

## Contenido

- `book/` - Notebooks de Jupyter que vienen del contenido del libro y repositorio adjunto [*Python Data Sciencie Handbook*](https://github.com/husseinlopez/PythonDataScienceHandbook/) de Jake VanderPlas.
- `classes/` - material de las sesiones de clase, como las presentaciones y libros.
- `notebooks/` - notebooks de Jupyter que nos dejan de tarea en clase.
- `practices/` - las prácticas del curso, cada una con su propio notebook.
- `project/` - el proyecto final de la materia.
